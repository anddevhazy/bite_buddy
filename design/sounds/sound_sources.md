# Game sounds

All from Kenney's packs (CC0: free for any use, no credit required), converted
to MP3 (iPhones can't play OGG) with even loudness, in
`frontend/assets/audio/`. The original packs are the zips in this folder.

| Game sound | File | From |
|---|---|---|
| Hit | `hit.mp3` | Impact Sounds: impactPunch_medium_000 |
| Heavy hit / critical | `heavy_hit.mp3` | Impact Sounds: impactPunch_heavy_000 |
| Block | `block.mp3` | Impact Sounds: impactPlate_light_000 |
| Perfect block | `perfect_block.mp3` | Impact Sounds: impactBell_heavy_002 |
| Dodge | `dodge.mp3` | RPG Audio: knifeSlice |
| Opponent winds up | `windup.mp3` | Interface Sounds: maximize_004 |
| Special | `special.mp3` | Impact Sounds: impactPunch_heavy_001 + impactGlass_heavy_001, mixed |
| Stun | `stun.mp3` | Interface Sounds: pluck_002 |
| Knockout | `knockout.mp3` | Impact Sounds: impactSoft_heavy_000 |
| Victory | `victory.mp3` | Music Jingles: jingles_STEEL07 (chosen without listening) |
| Defeat | `defeat.mp3` | Music Jingles: jingles_PIZZI07 (chosen without listening) |
| Countdown 3-2-1 | `countdown.mp3` | Interface Sounds: bong_001 |
| "Fight!" | `fight.mp3` | Interface Sounds: confirmation_002 |
| Button tap | `tap.mp3` | Interface Sounds: click_001 |
| Feeding your buddy | `feed.mp3` | Interface Sounds: confirmation_004 |
| Level up | `level_up.mp3` | Music Jingles: jingles_NES00 (chosen without listening) |

To swap a sound: ask Claude ("use jingles_SAX07 for victory"), or convert it
yourself and replace the file with the same name.
